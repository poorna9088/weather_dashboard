# ☀️ Atmos – Weather Dashboard

## 📌 Project Overview

Atmos is a modern, responsive Weather Dashboard developed using HTML, CSS, and JavaScript. It allows users to search for any city and view real-time weather information along with a five-day weather forecast.

## ✨ Features

- Search weather by city name.
- Display current temperature.
- Show weather conditions with dynamic weather icons.
- Display humidity and wind speed.
- Show feels-like temperature.
- Five-day weather forecast.
- Handle invalid city names and API errors.
- Responsive design for desktop and mobile devices.
- Real-time weather data using REST APIs.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- RESTful APIs
- JSON
- Open-Meteo Weather API

## 🌐 API Used

Weather data: https://open-meteo.com/

Geocoding API: https://open-meteo.com/en/docs/geocoding-api

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Enter a city name in the search bar.
5. Click Explore to view the weather information.
